# Security Policy

## Supported Versions

This project maintains a base template and version-specific branches. Security fixes apply to the latest commit on active branches.

| Branch | Supported |
| ------ | --------- |
| Active branches | Yes |

## Reporting a Vulnerability

Please **do not** open public issues for security vulnerabilities. Use GitHub's **Report a vulnerability** (Private Security Advisories) feature on this repository to report issues privately, including steps to reproduce and potential impact.

## Clean-Room & Legal Compliance

Never include proprietary SDK files, NDA material, cryptographic keys, non-zero retail passcodes, or console firmware dumps (`.sprx`, `.pup`) in bug reports, issues, or pull requests. Any submission containing proprietary material will be rejected and removed immediately.
